# AI 工具需求方案

本目录包含两个 AI 产品方向的需求文档与版本规划：

- AI 旅行规划助手：围绕行程生成、偏好约束和方案调整设计。
- 求职追踪工具：围绕岗位管理、JD 匹配、简历优化和面试准备设计。

## 在线阅读

[打开需求文档](https://4uiiowy.github.io/vicky-demo-repository/ai-tools-requirements/)

## 文件

- `index.html`：完整需求文档，可直接在浏览器中打开。
- `_shared/fonts/`：页面使用的本地字体资源。

需求文档用于展示产品分析与规划能力；其中的目标和指标属于方案设计，不代表已经取得的实际业务结果。
