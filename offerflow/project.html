核心问题

求职难的不是缺少一张表，而是岗位、材料和准备过程彼此断开。
Core workflow

从发现岗位，到带着证据走进面试

01 / CAPTURE

解析岗位

粘贴招聘链接，提取公司、岗位、地点与 JD，减少重复录入。

02 / MATCH

匹配简历

从简历事实中寻找能力证据，指出匹配项与信息缺口。

03 / TRACK

追踪进度

集中管理投递状态、下一步事项与关键时间节点。

04 / PREPARE

准备面试

围绕真实经历生成深挖问题，并按 STAR 结构组织回答。

Product system

不是替用户编故事，而是把已有经历变成可用证据

当前能力

动态岗位解析支持需要浏览器渲染的公开招聘页面。
多格式简历支持 PDF、DOCX、TXT 与 Markdown。
证据级匹配结论关联简历依据，缺失信息明确提示补充。
题库审核新问题先进入待确认区，避免污染核心题库。

Demo 边界

  • 数据保存在当前浏览器，不跨设备同步。
  • 免费实例闲置后会休眠，首次打开可能需要等待。
  • 招聘网站要求登录或触发验证码时，需要手动补充。
  • AI 内容不虚构经历，无证据处标记待补充。
