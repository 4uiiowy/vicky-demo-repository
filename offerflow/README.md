# OfferFlow V0.6

[项目介绍页](https://4uiiowy.github.io/vicky-demo-repository/offerflow/project.html) · [在线 Demo](https://offerflow-u2hq.onrender.com/)

## 启动

双击 `启动 OfferFlow.command`，终端会启动本地服务，浏览器随后打开：

`http://127.0.0.1:8765`

终端窗口需要保持打开。使用结束后，在终端按 `Control+C` 停止服务。

如果 macOS 首次阻止运行，可右键点击 `启动 OfferFlow.command`，选择“打开”。

也可以在当前目录运行：

```bash
python3 server.py
```

## 招聘链接解析

添加岗位时粘贴公开招聘链接，点击“一键解析”，服务会尝试填写：

- 公司名称
- 岗位名称
- 岗位 JD
- 工作地点
- 投递渠道

服务会先快速读取网页源码。如果岗位内容由 JavaScript 动态加载，会自动启动本机 Chrome/Edge 的独立无头会话，等待页面渲染后再提取内容。首次浏览器解析可能需要十几秒。

岗位已下线、要求登录、触发验证码或内容仅对特定账号开放时，服务会显示具体原因，并保留链接供手动填写。

## 数据

岗位和简历数据仍只保存在浏览器本地。建议定期在“设置”中导出 JSON 备份。

## 牛客校招日程

投递列表内嵌了牛客校招日程：

`https://www.nowcoder.com/jobs/school/schedule`

页面支持刷新、收起和在新标签页打开。内嵌内容由牛客提供；如果牛客调整跨站策略、要求登录或网络无法访问，使用“新标签页打开”继续查看，不会影响 OfferFlow 其他功能。

## 设备兼容与发布

页面已适配桌面、平板和手机宽度，并为窄屏优化了投递列表、顶部按钮、详情标签、弹窗和校招日程。

当前启动地址 `http://127.0.0.1:8765` 仅能在运行服务的这台电脑上访问。项目已包含可直接部署的 `Dockerfile` 和 `render.yaml`：

1. 将项目提交到 GitHub 仓库。
2. 在 Render 创建 Blueprint，并选择仓库中的 `render.yaml`。
3. 等待镜像构建完成，访问 Render 分配的 HTTPS 域名。
4. 打开 `/healthz`，确认 `ok`、`browser`、`pdf` 都为 `true`。

部署镜像内包含 Chromium、中文字库和 `pdftotext`，因此动态岗位页面、PDF/DOCX 简历解析与前端使用同一个公网域名。`render.yaml` 默认使用免费的 `free` 实例，并通过 `/healthz` 执行健康检查。

免费实例适合作品集 Demo，但可能在闲置后休眠，首次访问需要等待冷启动；内存也低于付费实例。为降低浏览器渲染导致的内存峰值，公开接口默认限制每个来源每分钟 15 次请求，浏览器渲染最多并行 1 个任务。可通过 `RATE_LIMIT_PER_MINUTE` 和 `BROWSER_MAX_CONCURRENCY` 调整。

## 当前数据边界

公网部署后，其他用户可以在电脑、平板和手机上打开完整页面，并使用云端解析接口。岗位、简历和面试答案目前仍保存在各自浏览器的 `localStorage` 中：

- 同一用户换设备后不会自动同步数据
- 清除浏览器数据会删除本机记录
- 多用户账号、云数据库、数据隔离和找回能力尚未实现

正式开放给多位用户前，下一阶段应增加用户登录、云数据库、权限隔离、服务端加密和备份策略。
