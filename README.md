# Vicky 的 AI 产品作品集

这个仓库收录两个相互独立的 AI 产品项目，分别展示内容审核工作流设计和求职工具开发能力。

[作品集首页](https://4uiiowy.github.io/vicky-demo-repository/) · [OfferFlow 在线 Demo](https://offerflow-u2hq.onrender.com/)

## 项目目录

| 项目 | 目录 | 内容 |
| --- | --- | --- |
| Case Review Tool | [`case-review-tool/`](./case-review-tool/) | 内容审核批次复核、证据阅读和结论标注的交互 Demo |
| OfferFlow | [`offerflow/`](./offerflow/) | 岗位解析、投递追踪、简历匹配和面试准备工具 |

## 在线入口

- [作品集导航页](https://4uiiowy.github.io/vicky-demo-repository/)
- [Case Review Tool](https://4uiiowy.github.io/vicky-demo-repository/case-review-tool/)
- [Case Review 交互 Demo](https://4uiiowy.github.io/vicky-demo-repository/case-review-tool/demo.html)
- [OfferFlow 在线 Demo](https://offerflow-u2hq.onrender.com/)

## 数据说明

公开页面不包含内部系统连接、公司代码或真实业务数据。Case Review Tool 使用合成案例；OfferFlow 的个人数据默认保存在浏览器本地。

## 仓库结构

```text
.
├── case-review-tool/
├── offerflow/
├── index.html
├── render.yaml
└── README.md
```

`render.yaml` 保留在根目录，用于将 `offerflow/` 部署为 Render 免费 Web Service。
