# Case Review Tool Showcase

一个以中文为主的零依赖静态作品集，展示批次复核、证据阅读与结论标注的产品设计。它是内部业务工具的公开、脱敏概念版，只复现产品思路和交互，不包含任何内部系统连接、真实业务数据或公司代码。

[项目页面](https://4uiiowy.github.io/vicky-demo-repository/case-review-tool/) · [交互 Demo](https://4uiiowy.github.io/vicky-demo-repository/case-review-tool/demo.html) · [作品集首页](https://4uiiowy.github.io/vicky-demo-repository/)

## 项目背景

内容复核通常需要在多个信息源之间切换：先定位 Case，再查找文本、画面和商品证据，最后回到表格记录结论。真正需要人的部分是理解证据与判断边界，而不是重复打开页面、寻找字段和搬运信息。

这个项目把流程重组为：

```text
批次输入 → 证据聚合 → 人工判断 → 结果保存 → 进度回看
```

公开版重点呈现三项能力：

- 产品抽象：把分散操作归纳为批次、证据、决策三个稳定对象。
- AI 辅助开发：使用 AI 完成需求拆解、技术探索、编码和测试，同时由业务 Case 验证输出。
- 合规设计：真实系统采用人工决策优先、模型能力可插拔的架构；公开仓库只使用合成数据。

## 本地运行

无需安装依赖。可直接打开 `index.html`，也可在当前目录启动任意静态文件服务器。

```bash
python3 -m http.server 8000
```

随后访问 `http://localhost:8000/`。

## 演示说明

- 所有名称、编号、摘要与证据均为专门编写的合成数据。
- 标签结果只保存在当前浏览器的本地存储中。
- 点击证据卡可展开结构化详情。
- 点击批次可切换不同待办集。
- 保存标签后会更新批次进度，并在短暂停顿后进入下一条。
- 左侧重置按钮可以清除本地演示状态。

## 技术栈

原生 HTML、CSS、JavaScript；不使用框架、构建工具、远程字体或第三方脚本。

## 公开版架构

```text
Synthetic batches
       ↓
Evidence rail ──→ Human decision panel
       ↓                   ↓
Case navigation      Browser localStorage
```

真实业务版与此公开版严格隔离。后者没有网络请求、认证、第三方 API 和数据写回能力。

## 设计取舍

- 不把“接入大模型”当成价值成立的前提，先优化证据组织和人工审核闭环。
- 不在公开版展示真实截图，以合成案例说明交互与信息架构。
- 不用预估值冒充实测效率，项目效果需以对照测试结果为准。
- 不复刻内部连接层，避免公开仓库成为访问内部系统的入口。

## 面试讲解顺序

1. 实习中的 Case Review 需要跨页面找证据，重复操作占用了判断时间。
2. 将流程拆成证据采集、证据清洗、人工判断和结果沉淀。
3. 通过 AI 辅助开发把业务经验转成可运行产品，并持续用真实工作流校验。
4. 因数据合规限制，没有接入个人 API，而是采用人工优先、模型可插拔方案。
5. 为公开求职展示另做合成数据版，证明产品与工程能力，同时保护内部信息。
